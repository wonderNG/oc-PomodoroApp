## 🚀 How to Run the App
Because this is an independent student project, the executable (`.exe`) is not signed with a commercial Windows certificate. When you run it for the first time, Windows SmartScreen will show a blue warning box.

To run the app, simply follow these two steps:
1. Click **"More info"** on the blue popup window.
2. Click **"Run anyway"**.

*Note: Windows will remember this choice and will not show this warning again on your computer.*
